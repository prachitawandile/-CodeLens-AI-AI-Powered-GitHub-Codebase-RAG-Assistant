System Architecture & RAG Pipeline

Overview & Workflow

This application implements a complete Retrieval-Augmented Generation (RAG) system for GitHub repositories:

  1. Clone & Filter: Shallow clones the repo and filters 20+ supported programming/markup file types, ignoring binaries and vendor folders (node_modules, venv, etc.).
  2. Chunking: Line-based sliding window (100 lines chunk, 15 lines overlap) preserving exact line numbers and file paths.
  3. Vector Embeddings: Generates 384-dimensional dense vectors using all-MiniLM-L6-v2 (Sentence-Transformers).
  4. ChromaDB: Persists embeddings, document text, and metadata in an isolated local collection with cosine similarity.
  5. Grounded LLM Answer: Retrieves top-5 relevant chunks, formats context, and prompts Google Gemini / OpenAI with strict grounding.
Environment Configuration: Set LLM_PROVIDER=gemini or openai and your LLM_API_KEY in the .env file.
